# Короткие видео для изучения английских слов

Вертикальные ролики 1080×1920 для TikTok / Reels / Shorts: красивый пейзаж на фоне,
слово, отсчёт с тиканьем, ответ с транскрипцией и озвучкой. Уровни A1–C2.

## Форматы

- **cards**: русское слово → отсчёт 3 с → английское слово + транскрипция + озвучка. 10 слов, ~63 с.
- **quiz**: «Как переводится X?» и три варианта → отсчёт → правильный ответ подсвечивается зелёным. 8 вопросов, ~62 с.

В конце каждого ролика есть карточка с призывом написать результат в комментариях.
Рядом с каждым видео сохраняется `.txt` с описанием, хэштегами и списком слов.

## Рекламный баннер

В каждом ролике в середине, на границе между словами,
делается пауза, и по центру экрана во всю ширину проигрывается баннер `assets/banner.mp4`
(место выбирается так, чтобы середина ролика попадала внутрь баннера):
ускорен в 1.3 раза, зелёный хромакей удалён, звук баннера сведён с роликом.
Новый баннер — просто заменить файл (или `--banner путь`), `--banner none` — ролик без баннера.
Ролики с баннером получаются 64–72 секунды.

## Запуск

Нужны Python 3.10+ и ffmpeg. Пошагово для Windows и полный контекст проекта: `CLAUDE.md`.

```bash
pip install edge-tts numpy pillow
export SSL_CERT_FILE=/путь/к/ca-bundle.crt     # только если сеть за прокси с собственным CA

python3 fetch_backgrounds.py catalog    # каталог роликов Mixkit -> bg/catalog.json
python3 fetch_backgrounds.py download   # скачать ролики из bg/curated.txt в 1080p
python3 make_video.py --level B1 --format cards --part 1
python3 batch.py --jobs 2               # всё сразу
```

## Где что лежит

- `words/A1.txt … C2.txt`: словари в формате `english | IPA | русский | ловушка 1 | ловушка 2`.
  Ловушки — неправильные варианты для квиза: похожие по написанию или смыслу слова.
- `bg/curated.txt`: какие фоны используются. Закомментируйте строку (`#- 1234`), чтобы убрать фон.
- `out/`: готовые видео.

## Источники

- Фоны: [Mixkit](https://mixkit.co/license/#videoFree), бесплатная лицензия, в том числе для коммерческого
  использования, без указания авторства. Берётся только 1080p (для неё действует бесплатная лицензия).
- Озвучка: нейроголоса Microsoft Edge через `edge-tts` (ru-RU-SvetlanaNeural, en-GB-SoniaNeural).
- Шрифты: Inter и Noto Sans (SIL Open Font License).
- Звуки (тиканье, «правильно») синтезируются в коде.

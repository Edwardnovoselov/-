# Короткие видео для изучения английских слов: контекст проекта

Этот файл передаёт контекст из облачной сессии Claude, где проект был сделан. Прочитай его целиком,
прежде чем что-то менять. Пользователь пишет по-русски, отвечай тоже по-русски. Компьютер пользователя на Windows.

## Первый запуск на Windows

Если папки с проектом ещё нет, выполни шаги сам в PowerShell. Если что-то требует действий
пользователя (вход в GitHub, подтверждение установщика), попроси его об этом.

```powershell
# 1. Инструменты (после установки открыть терминал заново, чтобы обновился PATH)
winget install --id Git.Git -e
winget install --id Python.Python.3.13 -e
winget install --id Gyan.FFmpeg -e

# 2. Код: ветка claude/english-videos репозитория Edwardnovoselov/-
#    Имя папки задаём явно: сам репозиторий называется "-"
git clone -b claude/english-videos https://github.com/Edwardnovoselov/-.git english-shorts
cd english-shorts\english-videos

# 3. Библиотеки Python
py -m pip install edge-tts numpy pillow

# 4. Фоны с Mixkit (64 ролика, ~3.3 ГБ). Повторять, пока в выводе не останется строк "fail":
#    если какого-то фона не хватает, ролики соберутся с другими фонами
py fetch_backgrounds.py download

# 5. Все ролики (уже готовые файлы в out\ пропускаются)
py batch.py --jobs 2
```

- Нужно около 10 ГБ свободного места: фоны ~3.3 ГБ, все ролики ~5.5 ГБ.
- На Windows (12 потоков) один ролик в одиночку собирается ~42 с. При `--jobs 3` 134 ролика собрались за 68 минут, ~31 с на ролик.
- Если `winget` просит принять условия Microsoft Store, добавь `--source winget`.
- `SSL_CERT_FILE` на Windows не нужен: он был только для прокси облачной среды.
- Результат пересборки детерминирован, то есть получатся те же 137 роликов. Seed слов, фонов и пауз фиксирован.
  Любая правка `bg/curated.txt` меняет фоны во всех роликах.
- Проверено на Windows 10: Python 3.13, ffmpeg 9.0.2, edge-tts 7.3, numpy 2.5, Pillow 12.3. В облаке раньше: ffmpeg 6.1.

## Что просил пользователь

1. Наделать много простых вертикальных роликов для изучения английских слов, похожих на его референсы.
   Нужны красивые места на фоне из бесплатных стоков или оформление квизом. Уровни A1–C2.
2. Длина 60–70 секунд. Лучше больше роликов, чем меньше по 120 секунд.
3. **Рекламный баннер в каждом ролике. Это условие выплаты.** Правила от пользователя:
   - баннер один, единственный;
   - в роликах до 2 минут он стоит 1 раз в середине, в роликах от 2 минут два раза: на 0:30 и на 1:30;
   - ролики со старым баннером не принимаются с 18.10.26;
   - баннер расположен в центре экрана;
   - скорость баннера увеличена до 1.3x;
   - баннер занимает не менее 25% от масштаба экрана;
   - хромакей на баннере удалён.
   Файл баннера: `assets/banner.mp4` (NATRIA VPN, 1770×750, 7.2 с, зелёный фон 0x00FE00).
   `NATRIA_VPN.mp4`, присланный повторно, побайтно совпадает с ним: альфа-канала нет, файл не ускорен,
   поэтому хромакей и ускорение 1.3x делает генератор.

## Что сделано

- Генератор (`make_video.py`), пакетный запуск (`batch.py`), загрузчик фонов (`fetch_backgrounds.py`), словари.
- Собрано 137 роликов с баннером:

  | Уровень | A1 | A2 | B1 | B2 | C1 | C2 |

  | Роликов | 27 | 21 | 20 | 23 | 23 | 23 |

  и что на точную середину приходится полностью открытый баннер.
- Ролики не лежат в git: они весят 5.5 ГБ. Актуальный набор лежит в `english-videos\out\`.

## Как устроено

### Форматы

- **cards**: 10 слов, ~63 с без баннера. Русское слово с озвучкой, отсчёт 3 с с кольцом и тиканьем,
  затем английское слово, транскрипция и британская озвучка.
- **quiz**: 8 вопросов, ~62 с без баннера. «Как переводится X?» и три варианта, отсчёт 4.5 с, правильный вариант
  подсвечивается зелёным с галочкой.
- Фон меняется каждые 2 слова плавным переходом. В конце идёт карточка «Сколько слов ты знал?» (cards) или
  «Сколько из N верно?» (quiz) и «Напиши в комментариях!».
- Рядом с каждым роликом сохраняется `out/<имя>.txt`: описание, хэштеги, список слов.
- Имена файлов: `out/{уровень}_{формат}_{номер:02d}.mp4`, например `out/B2_quiz_07.mp4`.
  Номер сдвигает набор слов: часть N берёт слова с позиции (N−1)·per_video из перемешанного словаря.
  Внутри одного формата слова не повторяются.

### Баннер (как сейчас сделано)

- Для роликов до 2 минут баннер вставляется один раз в паузу между словами. Ролик в этот момент как бы останавливается.
  Пауза из тишины: обычно 0.3–1.6 с до баннера (у трёх роликов до 2.74 с) и 0.35 с после.
- Место и длина паузы подбираются автоматически, чтобы на середину итогового ролика приходился полностью открытый баннер:
  не ближе 0.9 с к его началу и 0.6 с к концу (`BANNER_OPEN_*`). Он открыт с 0.77 по 5.03 с из 5.54 с.
  Если пауза не помогает, продлевается финальная карточка (`banner_tail`, сейчас только в C1_cards_02).
  Если условие не выполнено, лог рендера пишет «НЕ В СЕРЕДИНЕ».
- ffmpeg: `colorkey=0x00FE00:0.30:0.08,despill=type=green`, затем ускорение `setpts/1.3`, звук `atempo=1.3`.
  Масштаб: высота 486 px (`BANNER_H`), края обрезаются до ширины 1080 px, по центру. Это 25.3% площади кадра и 100% ширины.
  Звук баннера +7 дБ: исходник тихий.
- Режим «два баннера на 0:30 и 1:30» для роликов от 2 минут **не реализован**: все ролики короче 2 минут.
- Константы `BANNER*` вверху `make_video.py`. Флаг `--banner путь` подставляет другой баннер,
  `--banner none` собирает ролик без баннера.

### Визуал и звук

- Кадр 1080×1920, 30 fps. Python и Pillow рисуют прозрачный слой интерфейса на каждый кадр и передают его
  rawvideo в ffmpeg. ffmpeg кладёт слой поверх фонов, кадрированных под 9:16. Кодирование: libx264 superfast, crf 22, maxrate 5M, AAC 192k.
- Неподвижные куски не перерисовываются (`static_key`), основа кольца кэшируется.
- Цвет уровня: A1 (52,211,153), A2 (34,211,238), B1 (251,191,36), B2 (251,146,60), C1 (244,114,182), C2 (167,139,250).
- Шрифты в `assets/fonts`: Inter и Inter Display для текста, Noto Sans для транскрипции (в Inter нет символа ɪ).
- Озвучка: edge-tts, голоса `ru-RU-SvetlanaNeural` и `en-GB-SoniaNeural` (английский на скорости −8%).
  Кэш лежит в `cache/tts`, имя файла — хэш текста.
- Тиканье, щелчок и «правильно» синтезируются в numpy. Тиканье идёт каждые 0.5 с на −17 дБ.
  Итог: `volume=6dB` и `alimiter`, громкость около −13…−16 LUFS, под соцсети.

### Фоны

- Mixkit, бесплатная лицензия: можно для коммерции, без указания авторства. **Брать только 1080p**,
  на неё действует бесплатная лицензия.
- `bg/catalog.json` — каталог вертикальных роликов, `bg/curated.txt` — отобранные id (73 строки, 9 отключены через `#-`).
  `bg/clips.json` хранит размеры и длительности, `bg/clips/` хранит сами файлы (не в git).
- Скачивание идёт через официальный эндпоинт `mixkit.co/free-stock-video/download/{id}/?context=item&type=1080p`.
  Прямые ссылки на новые ролики дают 403 или только 360p.

### Словари

`words/A1.txt … C2.txt`, формат строки: `english | IPA (британская) | русский | ловушка 1 | ловушка 2`.
Ловушки — неправильные варианты для квиза, похожие по написанию или смыслу. Словари проверены:
нет повторов, ловушки не совпадают с ответом, IPA без лишних символов, омографы с разным произношением убраны.
Скобки в русском переводе на экране показываются, а в озвучке пропускаются.

### Команды

```powershell
py make_video.py --level B1 --format quiz --part 3            # один ролик
py make_video.py --level B1 --format quiz --part 3 --stills 5,20,33   # кадры PNG вместо видео
py make_video.py ... --handle @my.english                      # подпись канала (сейчас не используется)
py batch.py --levels A1,B2 --formats cards --jobs 2            # пакетно, существующие пропускаются
ffprobe -v error -show_entries format=duration -of csv=p=0 out\A1_cards_01.mp4   # длительность
```

Чтобы пересобрать ролик, удали его из `out\`. `batch.py` собирает только недостающие.

## Открытые вопросы (ждут решения пользователя)

1. **Реклама VPN.** В России реклама VPN запрещена с 1 марта 2024 года. Пользователь об этом предупреждён.
2. **Автопубликация раз в час.** Пользователь спрашивал, можно ли выкладывать по ролику каждый час. Ответ был дан,
   а площадки пользователь ещё не выбрал. Кратко:
   - 24 ролика в сутки на одном аккаунте похожи на спам и режут охваты. Обычно советуют 1–3 в день на площадку.
     137 роликов при раз в час закончатся через ~6 дней, при 3 в день хватит на ~45 дней.
   - Самый простой путь — отложенная публикация средствами площадок: YouTube Studio, TikTok Studio (до 10 дней вперёд),
     Meta Business Suite, отложенные записи VK, а также SMMplanner, Buffer, Metricool. Можно подготовить таблицу:
     файл, название, описание из `.txt`, время.
   - Через API на Windows: скрипт публикации и Планировщик заданий Windows раз в час. Компьютер при этом должен быть включён.
     Ограничения площадок:
     - Telegram-бот: проще всего, лимит файла 50 МБ, ролики весят ~40 МБ.
     - VK: по токену пользователя.
     - Instagram: профессиональный аккаунт, страница Facebook, приложение Meta, до 50 публикаций в сутки.
     - YouTube Data API: квота по умолчанию даёт ~6 загрузок в сутки. Пока Google не проверит приложение, ролики будут приватными.
     - TikTok: до проверки приложения публикует только приватно.

## Правила работы

- Не коммитить видео, фоны, кэш (`out/`, `bg/clips/`, `cache/` уже в `.gitignore`).
- Не просить пользователя присылать токены и пароли в чат. Пусть сам положит их в переменные среды Windows
  или в файл `.env`, внесённый в `.gitignore`. Скрипт читает их оттуда, а ты называешь, какая переменная нужна.
- Правила баннера не менять без пользователя: от них зависит выплата.
- Перед массовой пересборкой показать пользователю 1–2 примера.

## Грабли, которые уже решены

- В Inter нет символа ɪ, поэтому транскрипция набрана в Noto Sans.
- Параметры `acompressor` в ffmpeg линейные, а не в дБ, поэтому громкость сделана через `volume` и `alimiter`.
- Mixkit отдаёт 403 и 360p по прямым ссылкам на новые ролики, поэтому используется download-эндпоинт.
- Баннер не всегда закрывал середину ролика. Теперь место и паузу подбирает алгоритм в `__init__`
  класса ролика (`placement`). Запаса 0.5 с от краёв мало: баннер раскрывается и закрывается анимацией,
  и в такие моменты в кадре только логотип или пустая плашка.
- Клип Mixkit `4695` к концу уходит в чёрное, он отключён в `bg/curated.txt`. Новые фоны стоит проверять по яркости.
- Покадровое размытие кольца было слишком медленным. Сделан кэш основы кольца, пресет superfast и кэш неподвижных кадров.
